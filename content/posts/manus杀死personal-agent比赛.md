## 最近的两个瘫坐时刻

最近有两次，看完东西我在椅子上坐了很久。一次是 Opus 5.5，一次是 Manus 2.0。中间还夹着一个 Grok bot，没让我瘫坐，但正好能说明为什么另外两次会。

## Opus 5.5

Opus 5.5 刚出来的时候，我其实没什么感觉。跑分确实碾压 Astra 和 Fable，但跑分这种东西，每个月都有新的榜一，看多了就麻了。

而且我是真的不想再开会员了。Anthropic 那套封号政策一直让我很不舒服，订阅这件事我也已经够够的了：Codex 200 美金，Grok 300 美金，每个月都用不完。再加一个 Claude，怎么想都没必要。

最后还是开了个 Claude Code Max。

原因是我在 X 上刷到 p(doom) 发的一个视频。AI 是接收不了音乐的，它听不见。但这个视频里，AI 自己写代码去分析音乐，找节拍，按节拍踩点剪，最后出来的东西非常顶级，放在任何剪辑博主那里都不丢人。

它听不见，就写代码去"看"音乐。这个事给了我一点震撼。模型能力强我早就知道，但我没想过它能自己找路绕过去。

然后我就去开了会员。

## Grok bot 和一堆 personal agent

最近大家都在卷 personal agent。说实话，我感觉没什么意思。

Grok bot 我玩过了。形态确实容易上手，发条消息就能用，但除此之外，我找不出它有什么特别大的好处。硬要说还有一个：它带云电脑，环境是隔离的，我可以让它在云端帮我写点代码、调调 bug。相当于送了我一台 Linux 机器。挺好用，但也就这样了。

Grok bot 之后是 Muse，小扎的股票还因此涨了不知道多少。它主打生活场景，帮你订餐厅、订座位、打电话。

这些东西我们其实是无感的。

国内的生态太封闭了。流量入口牢牢握在几家巨头手里：支付得走支付宝和微信，聊天是微信，刷东西是抖音和小红书，买东西是淘宝和拼多多。每一家都不会让一个外来的 agent 随便进出。豆包手机 1.0 只是模拟点点屏幕，就直接折戟了，更别说让用户把自己的信息托管到一个云上。

国内本来也没那么多打电话的场景。订餐厅用美团，订座位用大众点评，谁还打电话。

所以这条路我非常不看好。这类 personal agent 是替你去操作别人的 App，可在国内，每一个 App 都是别人家的地盘。agent 要做的每一件事，都得先过巨头那一关。

## 没想象力这件事

我一直觉得，做 agent 应用的人没什么想象力。

这话不是贬低谁，因为我觉得自己也没想象力，太匮乏了。不然我早就创业去了，还打什么工呢。

AI 圈著名评论家咸鱼说过一句话：这些创始人一个个都是卷王，天天卷效率，卷完 coding 卷办公，疯掉了。普通人呢？普通人不需要这么高的效率。

我很认可。现在的 agent 产品，写代码快一点，写文档快一点，订个餐厅省两分钟，都是在帮你把活干快。但大部分人下班以后不想再干活，也不在乎快那两分钟。

效率工具还有个问题：用完就走。没人会没事打开一个订餐厅的 agent 逛一逛。

可我自己也想不到别的。效率、AI agent、娱乐性，这三样怎么放到一起，我想了很久也没想明白。能想到的，要么还是效率工具换个皮，要么就是做一个全是 AI 生成内容的抖音。

后者我觉得是 bullshit。把 AI slop 一条一条往信息流里灌，除了让垃圾变便宜，什么也没改变。

## Manus 2.0

原本我以为 personal agent 就到此为止了，然后 Manus 2.0 来了。这是我第二次瘫坐，它相当于给了我一片新大陆。

我一直觉得 Manus 是领先版本的。小扎花 20 亿美金买下 Manus，便宜得没边了。说白了，小红和 Peak 这两个人，给资源做什么都会成功。

现在创业缺的不是执行力。执行的成本已经太低了，写代码有 AI，做设计有 AI，缺的是场景，缺的是懂生活、有想象力的人。

那 Manus 给了我们什么场景？

它 2.0 的宣传片里，着重讲了两件事：剪视频和做游戏。

看到这里我想起了 p(doom) 那个视频。我都怀疑 Manus 是不是在 Anthropic 内部有人，早就知道 Opus 剪视频和做游戏这么强。

personal agent 本质上是一个卖电脑的生意，可能还兼着卖手机号。Grok bot 送我一台云端的 Linux 机器，Muse 帮我打电话，说到底都是这个。

如果一个人卖你电脑和手机，但是不能打游戏，也不能看视频，这有意思吗？

之前那些 personal agent 卖的就是这样的电脑。Manus 2.0 在这台电脑上装了游戏和视频。

## 它不用去求巨头

其他 personal agent 是替你去操作别人的 App，所以处处被巨头卡着。

Manus 不帮你去别人家办事，它自己做东西。视频是它做的，游戏是它做的，做出来就在它自己手里，不需要谁点头。

做东西的地方就是看东西的地方。你在 Manus 里做了一个游戏，发给朋友，朋友也在 Manus 里玩。内容本身就是入口，不用去抢别人的入口。

## 做出来的东西能改

这些视频和游戏是代码做出来的。

你在抖音刷到一个视频，它就是个视频文件，你只能看，最多点个赞、转发一下。代码做出来的东西，每一步都在那里：节拍怎么踩、画面怎么切、游戏规则怎么定，全都能改。

改它也不需要你会写代码。跟 agent 说一句"把音乐换成这首""主角换成我家猫""难度调低一点"，它就改好了。

我打开一个 personal agent，里面是别人精心做好的视频和游戏。我可以拿过来改成我自己的版本，再分发出去，别人又可以接着改。

这想象空间是不是有点太足了？

这不是 Roblox 吗？这不是 Notion 吗？

Roblox 说到底就是个游戏编辑器，Notion 说到底就是个笔记软件。但它们有两个共同点：什么都能做，做出来的东西能二次分发。一个人做了，别人拿过去改一改，又是一个新的，再接着传下去。它们的本质都是创造和分发。

Roblox 和 Notion 也有门槛。在 Roblox 上做游戏要学它的编辑器，在 Notion 上做个好模板也要花不少功夫。真正在上面创作的始终是一小部分人，大部分人只是在用别人做好的东西。

如果改一个东西只需要说一句话，这个门槛就没了。每个看的人都可以是改的人。

## 为什么是现在

这个想法不新，为什么现在才成立？

以前大家都觉得 AI 没有 taste，而内容是需要 taste 的。

抖音这种平台，不需要 10000 个 60 分的作品，它需要的是 1 个 90 分的作品被 10000 个人看。AI 以前只能做 60 分的东西，做再多也没用，那就是 AI slop。

创造和分发这套东西，前提是有人愿意看、愿意玩、愿意接着改。60 分的东西没人想改，也没人想传。

p(doom) 那个视频是 Opus 5.5 做的，对普通人来说，那已经是 80 分、90 分的东西了。

第一个作品够好，才会有人想改它。改出来的也够好，才会有人接着传。模型到了这个水平，这件事才转得起来。

## 这才是普通人要的

这才是兼顾效率和娱乐的地方。

普通人确实不需要那么高的效率，订餐厅快两分钟没人在乎。但如果效率能让我做出一个游戏、剪出一个视频，分享给朋友玩，让他们接着改，那就不一样了。

这才是普通人愿意去用的 personal agent。

我还是觉得自己没什么想象力。但至少这一次，我看到有人想到了。
