# 第六章：网络安全核心考点全覆盖

## 1. HTTPS 与 TLS/SSL (核心中的核心)

**① 核心概念解析**
HTTPS = HTTP + SSL/TLS，通过**加密传输**和**身份认证**保证网络通信安全。

**② TLS 握手过程详解**

* **TLS 1.2 握手流程**：
1. **Client Hello**：客户端发送支持的协议版本、随机数、加密套件列表
2. **Server Hello**：服务端确认协议版本、发送随机数、选择加密套件
3. **证书验证**：服务端发送数字证书，客户端验证证书有效性
4. **密钥交换**：使用非对称加密交换对称密钥
5. **完成握手**：双方确认握手完成，开始加密通信

* **TLS 1.3 优化**：
* **握手次数**：从2-RTT减少到1-RTT
* **加密套件**：移除不安全的加密算法
* **0-RTT恢复**：支持会话恢复，减少握手延迟

**③ 数字证书机制**

* **证书结构**：
* **证书信息**：版本、序列号、签名算法、颁发者、有效期、主体信息
* **公钥信息**：公钥算法、公钥值
* **数字签名**：CA用私钥对证书内容的哈希值加密

* **证书链验证**：
1. **验证叶子证书**：检查有效期、域名匹配
2. **验证签名**：用CA公钥验证证书签名
3. **构建证书链**：逐级验证到根证书
4. **根证书信任**：检查根证书是否在信任列表

**④ 深度追问**

* **对称加密 vs 非对称加密**：
* **对称加密**：AES、DES，加密解密用同一密钥，速度快
* **非对称加密**：RSA、ECC，有公钥私钥之分，速度慢
* **混合使用**：非对称加密交换密钥，对称加密传输数据

* **中间人攻击防护**：
* **证书绑定**：浏览器预装可信CA根证书
* **证书透明度**：公开记录所有证书签发
* **HSTS**：强制使用HTTPS连接

## 2. 网络攻击类型 (高频)

**① 常见攻击方式**

* **DDoS攻击**：
* **原理**：大量僵尸主机同时向目标发送请求
* **类型**：
  * **带宽消耗型**：UDP Flood、ICMP Flood
  * **资源消耗型**：SYN Flood、HTTP Flood
* **防御**：流量清洗、CDN、负载均衡、限流

* **SQL注入**：
* **原理**：在输入框中插入恶意SQL代码
* **危害**：数据泄露、数据篡改、系统控制
* **防御**：参数化查询、输入验证、最小权限原则

* **XSS攻击**：
* **反射型XSS**：恶意URL包含脚本，反射给受害者
* **存储型XSS**：恶意脚本存储在服务器，访问时执行
* **DOM型XSS**：修改DOM树执行恶意脚本
* **防御**：输出编码、CSP策略、输入验证

* **CSRF攻击**：
* **原理**：利用用户已登录状态，发送恶意请求
* **危害**：恶意转账、修改密码、删除数据
* **防御**：CSRF Token、SameSite Cookie、验证Referer

**② 深度追问**

* **XSS vs CSRF 区别**：
* **XSS**：攻击者在受害者浏览器执行脚本
* **CSRF**：攻击者冒充受害者发送请求
* **关系**：XSS可以用来辅助CSRF攻击

* **SQL注入防护最佳实践**：
* **预处理语句**：使用参数化查询
* **ORM框架**：避免手写SQL
* **权限控制**：数据库用户最小权限
* **审计日志**：记录异常SQL操作

## 3. 防火墙技术 (中频)

**① 防火墙类型**

* **包过滤防火墙**：
* **工作层次**：网络层、传输层
* **过滤依据**：源IP、目标IP、端口号、协议类型
* **优点**：速度快、配置简单
* **缺点**：无法检查应用层数据

* **状态检测防火墙**：
* **工作原理**：维护连接状态表，跟踪连接状态
* **过滤依据**：连接状态、包上下文关系
* **优点**：安全性更高、支持动态协议
* **缺点**：资源消耗大、性能较低

* **应用层防火墙**：
* **工作层次**：应用层
* **过滤依据**：应用协议内容、用户行为
* **优点**：精确控制、深度检测
* **缺点**：性能开销大、配置复杂

**② 防火墙策略**

* **默认策略**：
* **默认拒绝**：除明确允许外都拒绝（推荐）
* **默认允许**：除明确拒绝外都允许

* **规则顺序**：
* **从上到下匹配**：匹配第一条规则即执行
* **最后匹配**：未匹配任何规则时使用默认策略

* **常见规则**：
* **内网到外网**：允许HTTP、HTTPS、DNS
* **外网到内网**：只允许特定服务端口
* **DMZ区域**：允许Web服务器访问

**③ 深度追问**

* **防火墙 vs IDS vs IPS**：
* **防火墙**：访问控制，阻止非法访问
* **IDS**：入侵检测，发现攻击行为
* **IPS**：入侵防护，主动阻止攻击

* **下一代防火墙（NGFW）**：
* **应用识别**：识别具体应用而非端口
* **用户识别**：基于用户身份的策略
* **内容过滤**：检测恶意内容
* **SSL解密**：检查加密流量

## 4. VPN 技术 (中频)

**① VPN 基本原理**

* **核心概念**：通过公共网络建立安全的私有通道
* **关键技术**：隧道技术、加密技术、认证技术
* **主要作用**：远程访问、站点互联、安全传输

**② VPN 类型**

* **IPsec VPN**：
* **工作模式**：
  * **传输模式**：只加密数据部分，IP头不变
  * **隧道模式**：加密整个IP包，封装在新IP包中
* **协议组件**：AH（认证头）、ESP（封装安全载荷）
* **密钥交换**：IKE协议协商安全参数

* **SSL VPN**：
* **工作原理**：基于SSL/TLS建立安全通道
* **访问方式**：Web浏览器、专用客户端
* **优势**：穿透性强、配置简单、支持移动设备

* **MPLS VPN**：
* **工作原理**：基于MPLS标签转发
* **应用场景**：运营商专线、企业组网
* **优势**：服务质量保证、扩展性好

**③ 深度追问**

* **IPsec vs SSL VPN**：
* **IPsec VPN**：网络层VPN，适合站点互联
* **SSL VPN**：应用层VPN，适合远程访问
* **性能对比**：IPsec性能更好，SSL更灵活

* **VPN安全问题**：
* **密钥管理**：密钥分发和更新机制
* **认证机制**：用户身份验证方式
* **日志审计**：连接记录和异常检测

## 5. 网络安全协议 (中频)

**① 认证协议**

* **802.1X**：
* **架构**：Supplicant（客户端） + Authenticator（设备） + Authentication Server（服务器）
* **协议**：EAP（可扩展认证协议）
* **应用**：无线网络接入、有线网络接入

* **RADIUS**：
* **功能**：远程用户拨号认证服务
* **特点**：客户端/服务器架构、UDP传输
* **应用**：VPN认证、WiFi认证

* **TACACS+**：
* **功能**：终端访问控制器访问控制系统
* **特点**：TCP传输、分离认证授权计费
* **应用**：网络设备管理、特权访问控制

**② 加密协议**

* **IPsec**：
* **协议套件**：AH、ESP、IKE
* **工作模式**：传输模式、隧道模式
* **应用**：站点间VPN、远程访问

* **SSL/TLS**：
* **版本演进**：SSL 1.0/2.0/3.0 → TLS 1.0/1.1/1.2/1.3
* **握手过程**：身份认证、密钥交换、加密协商
* **应用**：HTTPS、VPN、邮件加密

**③ 深度追问**

* **RADIUS vs TACACS+**：
* **RADIUS**：认证授权合一，UDP传输
* **TACACS+**：认证授权分离，TCP传输
* **选择原则**：简单环境用RADIUS，复杂环境用TACACS+

* **TLS 1.3 vs TLS 1.2**：
* **握手优化**：减少RTT次数
* **加密算法**：移除不安全算法
* **前向保密**：强制使用前向保密

## 6. 其他重要考点 (低频)

* **`▽` 网络分段**：
* **目的**：限制攻击影响范围
* **方法**：VLAN划分、子网隔离、微分段
* **优势**：提高安全性、便于管理

* **`▽` 零信任架构**：
* **理念**：从不信任，总是验证
* **原则**：最小权限、持续验证、微隔离
* **实现**：身份认证、设备评估、行为分析

* **`▽` 安全监控**：
* **SIEM系统**：安全信息事件管理
* **日志分析**：异常行为检测
* **威胁情报**：攻击特征库更新

* **`▽` 合规性要求**：
* **等级保护**：网络安全等级保护制度
* **GDPR**：数据保护法规
* **PCI DSS**：支付卡行业数据安全标准

## 7. 网络安全常见面试追问总结

* **问：HTTPS是如何保证安全的？**
* 答：通过数字证书验证身份，非对称加密交换密钥，对称加密传输数据，保证机密性、完整性、认证性

* **问：什么是中间人攻击？如何防范？**
* 答：攻击者冒充通信双方，HTTPS通过证书验证、HSTS、证书透明度来防范

* **问：DDoS攻击的类型和防御方法？**
* 答：带宽消耗型、资源消耗型攻击，通过流量清洗、CDN、限流、负载均衡防御

* **问：SQL注入的原理和防护？**
* 答：在输入中插入恶意SQL代码，通过参数化查询、输入验证、最小权限原则防护

* **问：防火墙的工作原理和类型？**
* 答：包过滤、状态检测、应用层防火墙，基于规则控制网络访问
