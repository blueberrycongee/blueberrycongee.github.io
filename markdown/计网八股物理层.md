# 第五章：物理层核心考点全覆盖

## 1. 物理层基础概念 (核心中的核心)

**① 核心概念解析**
物理层是OSI模型的**最底层**，负责**比特流的透明传输**，定义了物理设备的标准和传输介质的特性。

**② 信号与编码基础**

* **信号类型**：
* **模拟信号**：连续变化的信号，如声音、光波
* **数字信号**：离散的信号值，如0和1
* **基带信号**：数字信号直接传输，适合近距离
* **宽带信号**：模拟信号调制传输，适合远距离

* **编码技术**：
* **不归零编码（NRZ）**：高电平为1，低电平为0
* **曼彻斯特编码**：位中间跳变，上跳为0，下跳为1
* **差分曼彻斯特**：位边界跳变，有跳为0，无跳为1
* **4B/5B编码**：每4位数据编码为5位信号

* **调制技术**：
* **幅移键控（ASK）**：用幅度变化表示0和1
* **频移键控（FSK）**：用频率变化表示0和1
* **相移键控（PSK）**：用相位变化表示0和1
* **正交幅度调制（QAM）**：结合幅度和相位调制

**③ 深度追问**

* **为什么需要编码？**
* **同步问题**：帮助接收方识别比特边界
* **直流平衡**：避免长时间高电平或低电平
* **错误检测**：某些编码具有检错能力
* **带宽效率**：提高频谱利用率

* **奈奎斯特定理**：
* **公式**：C = 2B × log₂V
* **含义**：无噪声信道的最大数据传输速率
* **参数**：B为带宽，V为信号状态数

* **香农定理**：
* **公式**：C = B × log₂(1 + S/N)
* **含义**：有噪声信道的最大数据传输速率
* **参数**：S/N为信噪比

## 2. 传输介质 (高频)

**① 有线传输介质**

* **双绞线（TP）**：
* **分类**：
  * **UTP（非屏蔽双绞线）**：无金属屏蔽层，成本低
  * **STP（屏蔽双绞线）**：有金属屏蔽层，抗干扰强
* **类别**：
  * **Cat3**：10Mbps，电话线
  * **Cat5/Cat5e**：100Mbps/1000Mbps，常用网线
  * **Cat6**：1000Mbps/10Gbps，高性能网络
* **接口**：RJ-45，8针连接器
* **传输距离**：100米（标准以太网）

* **光纤**：
* **分类**：
  * **多模光纤（MMF）**：纤芯较粗，距离较短（500m-2km）
  * **单模光纤（SMF）**：纤芯较细，距离较长（几十公里）
* **波长**：
  * **850nm**：多模光纤，短距离
  * **1310nm**：单模光纤，中距离
  * **1550nm**：单模光纤，长距离
* **优势**：带宽大、距离远、抗电磁干扰
* **接口**：LC、SC、ST等连接器

* **同轴电缆**：
* **结构**：中心铜导体 + 绝缘层 + 金属屏蔽层 + 外护套
* **分类**：
  * **基带同轴电缆**：传输数字信号，如10BASE5
  * **宽带同轴电缆**：传输模拟信号，如有线电视
* **特点**：抗干扰强，带宽适中

**② 无线传输介质**

* **无线电波**：
* **频段**：
  * **2.4GHz**：WiFi、蓝牙，距离远但干扰大
  * **5GHz**：WiFi 5/6，速度快但距离短
* **传播方式**：全向传播，易受障碍物影响

* **微波**：
* **特点**：直线传播，需要视距传输
* **应用**：卫星通信、地面微波中继
* **频段**：GHz级别，带宽大

* **红外线**：
* **特点**：直线传播，不能穿透障碍物
* **应用**：遥控器、短距离通信
* **优势**：不受无线电干扰，安全性好

**③ 深度追问**

* **双绞线为什么要双绞？**
* **减少串扰**：抵消相邻线对的电磁干扰
* **提高抗干扰能力**：外部干扰在两根线上产生共模信号
* **平衡传输**：差分信号提高信号质量

* **光纤为什么比铜缆快？**
* **带宽大**：光频率高，可用频谱宽
* **衰减小**：信号衰减小，传输距离远
* **抗干扰**：不受电磁干扰，信号质量好
* **安全性**：难以窃听，数据安全

## 3. 物理层设备 (中频)

**① 中继器（Repeater）**

* **功能**：信号再生和放大，延长传输距离
* **特点**：
  * **工作在物理层**：只处理比特流
  * **透明传输**：不改变帧内容
  * **延迟小**：简单放大，处理延迟低
* **限制**：最多4个中继器，最大传输距离受限

**② 集线器（Hub）**

* **功能**：多端口中继器，连接多个设备
* **特点**：
  * **共享带宽**：所有设备共享总带宽
  * **广播域**：所有端口在同一冲突域
  * **半双工**：同一时间只能一个方向传输
* **工作原理**：从一个端口接收，向所有其他端口转发

* **集线器vs交换机**：
| 特性 | 集线器 | 交换机 |
| --- | --- | --- |
| **工作层次** | 物理层 | 数据链路层 |
| **转发方式** | 广播 | 基于MAC地址 |
| **带宽** | 共享 | 独享 |
| **冲突域** | 所有端口 | 每个端口独立 |
| **安全性** | 低 | 高 |

**③ 收发器（Transceiver）**

* **功能**：信号转换，连接不同介质
* **类型**：
  * **电-光转换**：连接铜缆和光纤
  * **光-电转换**：连接光纤和铜缆
  * **多模-单模转换**：不同光纤类型转换
* **标准**：GBIC、SFP、SFP+、QSFP等

**④ 深度追问**

* **为什么集线器被淘汰？**
* **性能问题**：共享带宽，网络拥塞严重
* **安全问题**：所有数据广播，容易被窃听
* **冲突问题**：冲突域大，效率低下
* **交换机优势**：独享带宽，基于MAC转发

* **中继器的5-4-3规则**：
* **5个网段**：最多5个网段
* **4个中继器**：最多4个中继器
* **3个网段**：最多3个网段连接主机

## 4. 物理层标准与接口 (中频)

**① 以太网标准**

* **10BASE-T**：
* **速率**：10Mbps
* **介质**：双绞线（Cat3/Cat5）
* **距离**：100米
* **编码**：曼彻斯特编码

* **100BASE-TX**：
* **速率**：100Mbps
* **介质**：双绞线（Cat5）
* **距离**：100米
* **编码**：4B/5B + MLT-3

* **1000BASE-T**：
* **速率**：1000Mbps
* **介质**：双绞线（Cat5e/Cat6）
* **距离**：100米
* **编码**：8B/10B + PAM-5

* **10GBASE-T**：
* **速率**：10Gbps
* **介质**：双绞线（Cat6a/Cat7）
* **距离**：100米
* **编码**：64B/66B + LDPC

**② 接口标准**

* **RJ-45**：
* **针脚定义**：8针，使用1-2-3-6针脚
* **线序标准**：T568A、T568B
* **应用**：双绞线连接

* **光纤接口**：
* **LC**：小型化，高密度连接
* **SC**：推拉式，易于使用
* **ST**：螺纹连接，稳定性好
* **FC**：螺纹连接，高可靠性

**③ 深度追问**

* **T568A vs T568B线序**：
* **T568A**：绿白-绿-橙白-蓝-蓝白-橙-棕白-棕
* **T568B**：橙白-橙-绿白-蓝-蓝白-绿-棕白-棕
* **交叉线**：一端T568A，另一端T568B
* **直通线**：两端相同线序

* **为什么需要交叉线？**
* **早期设备**：网卡和网卡连接需要交叉
* **现代设备**：支持MDI/MDIX自动识别
* **应用场景**：旧设备连接、特殊网络配置

## 5. 其他重要考点 (低频)

* **`▽` 串行vs并行传输**：
* **串行传输**：逐位传输，距离远，速度相对慢
* **并行传输**：同时传输多位，距离短，速度快
* **应用**：串行用于长距离，并行用于短距离

* **`▽` 同步vs异步传输**：
* **同步传输**：时钟同步，块传输，效率高
* **异步传输**：起止位同步，字符传输，灵活性高
* **应用**：同步用于网络，异步用于串口通信

* **`▽` 多路复用技术**：
* **频分复用（FDM）**：按频率划分信道
* **时分复用（TDM）**：按时间划分信道
* **波分复用（WDM）**：按波长划分信道
* **码分复用（CDM）**：按编码区分信道

* **`▽` 物理层性能指标**：
* **带宽**：信道频率范围
* **速率**：数据传输速度
* **时延**：信号传输时间
* **误码率**：传输错误率

## 6. 物理层常见面试追问总结

* **问：双绞线为什么要绞合？**
* 答：减少电磁干扰，抵消串扰，提高信号质量

* **问：光纤和铜缆的区别？**
* 答：光纤带宽大、距离远、抗干扰，铜缆成本低、易维护

* **问：集线器和交换机的区别？**
* 答：集线器工作在物理层，广播转发；交换机工作在数据链路层，基于MAC转发

* **问：什么是曼彻斯特编码？有什么特点？**
* 答：位中间跳变编码，自带时钟同步，无直流分量，带宽效率低

* **问：为什么需要中继器？**
* 答：信号衰减补偿，延长传输距离，信号再生整形
